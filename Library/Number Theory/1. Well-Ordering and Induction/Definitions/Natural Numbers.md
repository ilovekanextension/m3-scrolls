**Definition.** The closure of the singleton $\{0\}$ under the successor function $\text{succ}:\mathbb{R}\to \mathbb{R}$ is called the set of **natural numbers** and is denoted as $\mathbb{N}$. Thus, the set $\mathbb{N}$ has the following properties:
- $0\in \mathbb{N}$.
- For all $n\in \mathbb{N}$, we have $\text{succ}(n)\in \mathbb{N}$ or, by definition, $n+1\in \mathbb{N}$.
- For all sets $S\subseteq \mathbb{R}$, if $0\in S$ and $n+1\in S$ for all $n\in S$, then $\mathbb{N}\subseteq S$.

If $n\in \mathbb{N}$, we say that $n$ is a **natural number**. The standard examples of natural numbers such as $2$ and $3$ can now be used intuitively since natural numbers have been formally defined.
