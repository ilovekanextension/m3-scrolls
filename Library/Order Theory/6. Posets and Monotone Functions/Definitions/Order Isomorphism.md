**Definition.** Let $A$ and $B$ be posets. A monotone function $f:A\to B$ is called an **order isomorphism** if it satisfies any (and therefore, by [[Order Isomorphisms as Monotone Bijective Functions With Monotone Inverses]], all) of the following properties.
1. $f$ is an isomorphism in $\mathsf{Pos}$.
2. $f$ is bijective, and the inverse $f^{-1}$ is monotone.
