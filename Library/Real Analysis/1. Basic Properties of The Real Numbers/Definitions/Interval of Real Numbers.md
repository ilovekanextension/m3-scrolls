**Definition.** Let $S\subseteq \mathbb{R}$.
1. We say that $S$ is an **open interval** if there are $a,b\in \mathbb{R}$ with $a<b$ such that $$S=\{x\in \mathbb{R}\mid a<x<b\}.$$We then denote $S$ as $(a,b)$ (not to be confused with the ordered pair notation).
2. We say that $S$ is a **closed interval** if there are $a,b\in \mathbb{R}$ with $a<b$ such that $$S=\{x\in \mathbb{R}\mid a\leq x\leq b\}.$$We then denote $S$ as $[a,b]$.
3. We say that $S$ is a **half-open interval** if there are $a,b\in \mathbb{R}$ with $a<b$ such that $$S=\{x\in \mathbb{R}\mid a\leq x<b\}\vee S=\{x\in \mathbb{R}\mid a<x\leq b\}.$$We then denote $S$ as $[a,b)$ and $(a,b]$ for the first and second case respectively.
