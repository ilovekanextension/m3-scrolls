**Definition.** Let $a\in \mathbb{R}$.
- We say that $a$ is **positive** if $a>0$. The set of all positive real numbers is denoted as $\mathbb{R}^+$ or $(0,\infty)$.
- We say that $a$ is **nonnegative** if $a\geq 0$. The set of all nonnegative real numbers is denoted as $\mathbb{R}^{\geq 0}$ or $[0,\infty)$.
- We say that $a$ is **negative** if $a< 0$. The set of all negative real numbers is denoted as $\mathbb{R}^-$ or $(-\infty,0)$.
- We say that $a$ is **nonpositive** if $a\leq 0$. The set of all nonpositive real numbers is denoted as $\mathbb{R}^{\leq 0}$ or $(-\infty,0]$.
