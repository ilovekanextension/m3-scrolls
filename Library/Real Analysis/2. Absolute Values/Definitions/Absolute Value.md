**Definition.** The **absolute value** $|{-}|:\mathbb{R}\to \mathbb{R}$ is defined as
$$|x|=
\begin{cases}
x & x\geq 0, \\
-x & x\leq 0.
\end{cases}
$$
This function is well-defined since $0=-0$ by [[Inverses of Group Identities]].
