**Definition.** A set $A$ is called a **doubleton** if there are objects $x$ and $y$ such that for all objects $a$, $$a\in A\iff(a=x\vee a=y).$$In this case, we then say that $A$ is the doubleton with elements $x$ and $y$ and denote it as $\{x,y\}$. Note that in this case $x$ and $y$ are not necessarily distinct, so singletons are doubletons.

In set builder notation, $\{x,y\}=\{a\mid a=x\vee a=y\}$.
