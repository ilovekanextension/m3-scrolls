**Definition.** The set of (precisely) all objects that satisfy a proposition $\varphi$ is denoted $$\{x\mid \varphi(x)\}.$$Therefore, $y\in\{x\mid \varphi(x)\}$ if and only if $\varphi(y)$. Note that in this notation $x$ is a dummy variable, so we could have used notations such as $\{z\mid \varphi(z)\}$ and $\{a\mid \varphi(a)\}$ to denote the same set.

More generally, the set of (precisely) all objects of the form $\mu_{x}$, where $x$ satisfies a proposition $\varphi$, is denoted $$\{\mu_{x}\mid \varphi(x)\}.$$
