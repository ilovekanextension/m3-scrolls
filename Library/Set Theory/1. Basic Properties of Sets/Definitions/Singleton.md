**Definition.** A set $A$ is called a **singleton** if there is an object $x$ such that for all objects $a$, $$a\in A\iff a=x.$$In this case, we then say that $A$ is the singleton with element $x$ and denote it as $\{x\}$.

In set-builder notation, $\{x\}=\{a\mid a=x\}$.
