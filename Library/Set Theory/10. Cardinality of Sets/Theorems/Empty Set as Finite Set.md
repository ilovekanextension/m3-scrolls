**Theorem.** The empty set $\varnothing$ is finite. In fact, $\varnothing\cong\mathbb{N}_{0}$.

**Proof.** Pick $n=0$. By [[Positivity of Squares of Real Numbers]], $0<1$. Therefore, by trichotomy of $<$, $$\mathbb{N}_{0}=\{m\in \mathbb{N}\mid 1\leq m\leq 0\}=\varnothing.$$By [[Isomorphism Relation as Equivalence Relation]], we then have $\varnothing\cong \mathbb{N}_{0}$. $\blacksquare$
