**Theorem.** Let $m,n\in \mathbb{N}$, and suppose that $\mathbb{N}_{m}\cong \mathbb{N}_{n}$. Then, $m=n$.

**Proof.** Define a proposition $\varphi$ on $\mathbb{N}$ as $$\varphi(x):\equiv \forall y\in \mathbb{N} \ (\mathbb{N}_{x}\cong \mathbb{N}_{y}\Rightarrow x=y).$$To prove the statement, it is enough to show that $\varphi(x)$ is true when $x=m$; from this we have $\forall y\in \mathbb{N} \ (\mathbb{N}_{m}\cong\mathbb{N}_{y}\Rightarrow m=y)$, so in particular, since $n\in \mathbb{N}$ and $\mathbb{N}_{m}\cong \mathbb{N}_{n}$ we have $m=n$. We will show by [[Principle of Mathematical Induction]] that $\varphi(x)$ is actually true for all $x\in \mathbb{N}$.
- **Base Case.** Suppose $y\in \mathbb{N}$, and suppose that $\mathbb{N}_{0}\cong \mathbb{N}_{y}$. Then, by [[Empty Set as Finite Set]], since $\varnothing\cong\mathbb{N}_{0}$, we have $\varnothing\cong\mathbb{N}_{y}$. Now, by [[Normal Forms of Natural Numbers]], $y=0$ or $y=k+1$ for some $k\in \mathbb{N}$. We will show that $\neg(\exists k\in \mathbb{N} \ y=k+1)$; from this we can conclude that $y=0$.
  
  For the sake of negation, assume that we can choose $k\in \mathbb{N}$ such that $y=k+1$. Then, by [[Natural Index Sets with Nonzero Length as Nonempty Sets]], $y\in \mathbb{N}_{y}$. Now, since $\varnothing\cong\mathbb{N}_{y}$, we can choose a bijection $f:\mathbb{N}_{y}\to\varnothing$. We have $y\in \mathbb{N}_{y}$, so $f(y)\in\varnothing$. This contradicts the fact that $\varnothing$ is empty.
- **Induction Step.** Suppose $x\in \mathbb{N}$, and suppose that $\varphi(x)$ is true. Suppose $y\in \mathbb{N}$, and suppose that $\mathbb{N}_{x+1}\cong\mathbb{N}_{y}$. This contradicts the fact that $\varnothing$ is empty. Therefore, $y\neq 0$.
